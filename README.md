# Thushouse Academy

เว็บไซต์โรงเรียนออนไลน์ Thushouse (ธีม ม่วง–ดำ) — เป็น static site ใช้ HTML/CSS/JS ล้วน ไม่ต้องติดตั้งอะไร

## หน้าเว็บ
| ไฟล์ | หน้า |
|---|---|
| `index.html` | หน้าแรก: Hero, คอร์ส + Bundle, ทำไมต้องเรียนกับเรา, 3 ขั้นตอน, รีวิว, FAQ |
| `course.html?id=...` | รายละเอียดคอร์ส + เนื้อหาในคอร์ส |
| `checkout.html?id=...` | ชำระเงิน: กรอกข้อมูล, เลขบัญชี, แนบสลิป, ใส่โค้ดส่วนลด |
| `login.html` | เข้าสู่ระบบ / สมัครสมาชิก |

มี **วงล้อส่วนลด** (กดที่แถบ "หมุนวงล้อเพื่อรับส่วนลด") ได้โค้ด `THUS5` / `THUS10` / `THUS15` ไปใช้ในหน้าชำระเงิน

## แก้ไขเนื้อหา
แก้ทุกอย่างได้ที่ `assets/courses.js` ไฟล์เดียว:
- `SITE` — LINE, เลขบัญชีธนาคาร
- `COURSES` — ชื่อคอร์ส ราคา บทเรียน เนื้อหา
- `BUNDLE`, `REVIEWS`, `FAQS`

สี/ธีมอยู่ที่ `assets/style.css` (ตัวแปรใน `:root`) · เมนูและ footer อยู่ที่ `assets/layout.js`

## ดูบนเครื่อง
เปิด `index.html` ในเบราว์เซอร์ได้เลย

## ขึ้นเว็บจริง (ฟรี)
GitHub → Settings → Pages → Source: branch `main` / root → จะได้ลิงก์ `https://<user>.github.io/thus-house/`
