## 1. ระดับผู้ใช้ (Role)

| ระดับ | ทำอะไรได้ |
|---|---|
| **Head Admin** (สูงสุด) | ทำได้ทุกอย่าง รวมถึงสร้าง/แก้นิยาม Role และจัดการ Head Admin คนอื่น |
| **Admin** | ทุกเมนูหลังบ้าน **ยกเว้น** เปลี่ยน Role ตัวเอง · แตะบัญชี Head Admin · แก้นิยาม Role |
| **Mentor** | สูงกว่าสมาชิกนิดเดียว: เลือกสมาชิกมาดูแล + จดโน้ตประวัติ |
| **Member** (ต่ำสุด) | เรียนคอร์สที่ซื้อ, คอมเมนต์, ถามผู้สอน |

- **1 คนมีได้หลาย Role** — Role หลัก + Role เพิ่มเติม สิทธิ์รวมกัน (เช่น Admin + Mentor)
- **ให้ Role ได้เฉพาะที่ต่ำกว่าตัวเอง** (Head Admin ให้ได้ทุก Role)
- บัญชีเจ้าของระบบ (อีเมลที่ตั้งใน `NEXT_PUBLIC_ADMIN_EMAILS`) เป็น Head Admin เสมอ แก้จากหน้าเว็บไม่ได้ — กันล็อกตัวเองออก

## 2. ผู้เยี่ยมชม (ยังไม่ล็อกอิน)

- **หน้าแรก** — แนะนำ THUS Member, จุดเด่น (เรียนสด / Class ปรับพื้นฐาน / วิดีโอย้อนหลัง), หลักสูตร, คลาสที่เปิดอยู่
- **ปุ่ม ☀️/🌙** สลับโหมดสว่าง/มืด (ค่าเริ่มต้นมืด · เว็บจำค่าที่เลือก)
- **Feedback** — รูปรีวิวจากสมาชิก · **Meetup** — สไลด์รูปกิจกรรม
- **ติดตาม THUS House** (ท้ายหน้าแรก + ไอคอนใน Footer ทุกหน้า): Facebook · YouTube · Instagram · TikTok
- **สมัครสมาชิก** (`/signup`): ชื่อ–นามสกุล, ชื่อเล่น, เบอร์โทร, **วันเดือนปีเกิด (วัน/เดือน/ปี พ.ศ.)**, อีเมล, รหัสผ่าน
  - ปกติต้องกดลิงก์ยืนยันในอีเมลก่อนเข้าได้
  - ถ้าระบบส่งอีเมลไม่ได้ ยังสมัครได้ แต่ต้องรอทีมงาน "ยืนยันอีเมลแทน"

## 3. สมาชิก (Member)

### 3.1 ล็อกอิน — ใช้ได้ทีละ 1 เครื่อง
- เข้าเครื่องใหม่ไม่ได้ ถ้ายังไม่ได้กด **ออกจากระบบ** ที่เครื่องเดิม
- เครื่องเดิมไม่ได้ใช้งานเกิน **24 ชม.** → ระบบปล่อยให้เครื่องใหม่เข้าได้เอง
- ทำเครื่องหาย/ลืมออก → ให้ทีมงานกด **"ปลดล็อกอุปกรณ์"** (Admin → สมาชิก → รายละเอียด)
- ทีมงาน (Role อื่นที่ไม่ใช่ Member) ไม่โดนล็อก

### 3.2 Dashboard (`/dashboard`)
- ทักด้วยชื่อเล่น · **My Classes** การ์ดคลาสที่ซื้อ + % ความคืบหน้า + วันหมดสิทธิ์
- **Live Classes** ที่กำลังจะมาถึง · คลาสอื่นที่ซื้อเพิ่มได้
- แจ้งเตือนถ้ามีสลิปรอตรวจ / บัญชีไม่ได้ใช้งาน

### 3.3 หน้าเรียน (`/classes/[id]`)
- รายชื่อบทเรียนทั้งหมด **พร้อมภาพปกของแต่ละคลิป** (✓ = ดูแล้ว) · กดเรียนทีละบท
- วิดีโอ **YouTube (Unlisted)** เล่นด้วยปุ่มของเว็บ (กดออกไป YouTube ไม่ได้) · มีปุ่มเต็มจอ (รองรับ iPhone) · Google Drive ก็เล่นได้
- นับความคืบหน้าจากการดูจริง
- บนมือถือ: วิดีโอ → **รายการบทเรียน** → คอมเมนต์ (เห็นทันทีว่ามีกี่บท) · จอคอม: รายการบทเรียนอยู่ขวา
- **คอมเมนต์** แสดง**รวมทุกคลิปในคลาสเดียวกัน** — ต่อท้ายว่า "(คลิปนี้)" หรือ "(จากคลิป บทที่ N · ชื่อคลิป)" กดเพื่อไปคลิปนั้นได้ · คอมเมนต์ใหม่ผูกกับคลิปที่เปิดอยู่ · ตอบกลับผูกกับคลิปของกระทู้นั้น
  - ชื่อแสดงเป็น **รหัสสมาชิก + ชื่อเล่น** (เช่น THUS-024 บอส) + รูปโปรไฟล์
  - ตอบกลับได้ 1 ชั้น · กดหัวใจคอมเมนต์ได้
  - **ลบได้เฉพาะคอมเมนต์ของตัวเอง**
  - มีคนตอบ → แจ้งเตือน 🔔
- **หัวใจบทเรียน** ("ชอบบทเรียนนี้") + แถว "ถูกใจโดย …" → กดดูรายชื่อทุกคนที่กดหัวใจ
- **📎 เอกสารประกอบคลาส** (เหนือวิดีโอ) — กดแล้วเปิด Google Drive / Docs / Sheets / Slides ในแท็บใหม่ · เห็นเฉพาะคนที่มีสิทธิ์เรียนคลาสนั้น

### 3.4 ถามผู้สอน (`/messages`)
- ส่งคำถาม/Feedback ถึงผู้สอน (เลือกคอร์สได้) → ทีมงานตอบ → ได้แจ้งเตือน 🔔

### 3.5 แจ้งเตือน 🔔 (มุมขวาบน)
- สลิปได้รับ/อนุมัติ/ปฏิเสธ · มีคนตอบคอมเมนต์ · ผู้สอนตอบข้อความ · สิทธิ์ใกล้หมดอายุ · ประกาศจากทีมงาน

### 3.6 โปรไฟล์ (`/profile`)
| ช่อง | หมายเหตุ |
|---|---|
| รูปโปรไฟล์ | อัปโหลด → ระบบย่อเหลือ 256px (~20KB) ให้เอง · เปลี่ยน/ลบได้ |
| รหัสสมาชิก | **แก้เองได้** (A–Z, 0–9, -, _ · ห้ามซ้ำคนอื่น) |
| ชื่อ–นามสกุล / ชื่อเล่น / เบอร์โทร | แก้ได้ |
| วันเดือนปีเกิด | เลือก วัน/เดือน/ปี พ.ศ. |
| เลขบัตรประชาชน 🔒 | ตรวจเลขถูกต้องก่อนบันทึก · **เก็บแบบเข้ารหัส** · ปกติแสดง `•••••••••1234` กด "แสดง" ถึงเห็นเต็ม |
| ที่อยู่ | สำหรับออกใบกำกับภาษี |
| ประสบการณ์ & เป้าหมาย | ตลาดที่เคยเทรด (เลือกหลายอย่าง) · ประสบการณ์ (ปี) · เป้าหมายในการเรียน |
- ด้านล่าง: **ประวัติการสั่งซื้อ** + สถานะ + เหตุผลถ้าถูกปฏิเสธ + วันหมดสิทธิ์
- ปุ่ม **ออกจากระบบ** (ต้องกดก่อนย้ายไปเครื่องอื่น)

### 3.7 ซื้อคลาส / ชำระเงิน (`/payment`)
1. **ต้องกรอกข้อมูลให้ครบก่อน** — ถ้ายังขาด จะขึ้นเช็กลิสต์ + ปุ่ม **"ไปกรอกข้อมูล →"**
   - ข้อที่บังคับ: ชื่อ, ชื่อเล่น, เบอร์, วันเกิด, เลขบัตร, ที่อยู่, ประสบการณ์, ตลาดที่เคยเทรด (ยกเว้นเลือก "ยังไม่เคยเทรด"), เป้าหมาย
   - หน้าโปรไฟล์ไฮไลต์ช่องที่ขาดเป็นสีส้ม "จำเป็น" → กรอกครบมีปุ่ม **"ไปชำระเงินต่อ →"**
2. เลือกคอร์ส → โอนเข้าบัญชีที่แสดง
3. **โค้ดส่วนลด** (ถ้ามี): กรอก → กด "ใช้โค้ด" → เห็น ราคาเต็ม / ส่วนลด / **ยอดชำระสุดท้าย** + **รหัสยืนยันโค้ด** (เช่น `D-7K3Q9A`)
4. แนบสลิป (PNG/JPG ≤ 4MB · ระบบย่อรูปให้) → "ยืนยันการชำระเงิน"
   - ยอด 0 บาท (โค้ดลดเต็ม) ไม่ต้องแนบสลิป
5. รอทีมงานอนุมัติ → ได้แจ้งเตือน → เริ่มเรียนได้
- สิทธิ์หมดอายุแล้ว **ซื้อต่ออายุได้** · สงวนสิทธิ์คืนเงินทุกกรณี

## 4. Mentor

เมนู **Admin → 🧭 สมาชิกที่ฉันดูแล**
- **"+ เลือกสมาชิก"** → รายชื่อสมาชิกที่ **ยังไม่มี Mentor** (คนที่ Mentor อื่นเลือกไปแล้วไม่ขึ้น) · พิมพ์กรองด้วยรหัส/ชื่อ → กด **"+ ดูแล"**
- สมาชิก 1 คน มี Mentor ได้คนเดียว
- กดชื่อสมาชิกในรายการ → เห็น:
  - ชื่อ, รหัส, เบอร์, อีเมล, สถานะ, เข้าสู่ระบบล่าสุด
  - วันเกิด, ตลาดที่เคยเทรด, ประสบการณ์, เป้าหมาย
  - คอร์สที่ซื้อ + วันหมดสิทธิ์
  - **กิจกรรมล่าสุด 30 รายการ**
- **📝 โน้ตประวัติสมาชิก** — จดได้เรื่อยๆ (สมาชิกไม่เห็น) · ลบได้เฉพาะโน้ตตัวเอง
- **"เลิกดูแล"** — เอาออกจากรายการ (โน้ตยังอยู่)
- Mentor **ไม่เห็น** เลขบัตรประชาชน และที่อยู่

## 5. Admin — เมนูหลังบ้าน (`/admin`)

> บนมือถือ: กดปุ่ม **☰** มุมบนเพื่อเปิดเมนูแนวตั้ง · ตัวเลขสีส้ม = งานที่รออยู่

### ▦ Dashboard
- ตัวเลขภาพรวม: สมาชิกทั้งหมด, รายได้รวม, การซื้อที่อนุมัติ, คอร์สยอดนิยม + กราฟ · แจ้งถ้ามีสมาชิกรอยืนยันอีเมล
- Role ที่ไม่มีสิทธิ์ดูตัวเลข (เช่น Mentor) เห็นแค่หน้าต้อนรับ ใช้เมนูตามสิทธิ์

### ✓ อนุมัติการชำระเงิน
- การ์ดสลิปทั้งหมด (รอตรวจ/อนุมัติ/ปฏิเสธ) · มีป้าย 🏷 ถ้าใช้โค้ดส่วนลด
- กดดูสลิป → ตรวจ **ยอดที่ต้องชำระ**, **โค้ดส่วนลด + ส่วนลด + ราคาเต็ม + รหัสยืนยันโค้ด** → **อนุมัติ** หรือ **ปฏิเสธ (ใส่เหตุผล)**
- อนุมัติ = เปิดสิทธิ์เรียนตามอายุของคลาส · แก้วันหมดสิทธิ์ภายหลังได้ที่หน้าสมาชิก

### 👥 สมาชิก
- ค้นหา ชื่อ/ชื่อเล่น/รหัส/อีเมล/เบอร์ · กรองสถานะ · "รอยืนยันอีเมล" กด **ยืนยัน** แทนได้
- **"✎ แก้หลายคน"** — แก้ **รหัสสมาชิก / ชื่อเล่น / สถานะ** ในตาราง (ทีละ 200 คน) แถวที่แก้เป็นสีม่วง → **"บันทึกทั้งหมด"** (เช็กรหัสซ้ำให้)
- **หน้ารายละเอียดสมาชิก**
  - รหัสสมาชิก, ชื่อเล่น (แก้ได้), อีเมล, ยืนยันอีเมล, เบอร์, วันสมัคร, เข้าสู่ระบบล่าสุด
  - **อุปกรณ์ที่ล็อกอิน** + ปุ่ม **"ปลดล็อกอุปกรณ์"**
  - สถานะ: ใช้งาน / ไม่ใช้งาน (ดูวิดีโอไม่ได้) / ระงับ (ล็อกอินไม่ได้)
  - **Role หลัก** + **Role เพิ่มเติม** (ปุ่ม + / ✓) · Mentor ที่ดูแลคนนี้
  - Discord ID (สำหรับกดอนุมัติใน Discord — เฉพาะผู้จัดการ Role)
  - การซื้อ + ความคืบหน้า + **แก้วันหมดสิทธิ์** (ว่าง = ไม่หมดอายุ)
  - **ข้อมูลส่วนตัว & การเทรด** + **เลขบัตรประชาชน** (กด "แสดง" — บันทึกใน Log ทุกครั้ง)
  - **📝 โน้ตประวัติ** (Admin ลบโน้ตได้ทุกอัน)
  - **กิจกรรมของสมาชิก** 200 รายการล่าสุด · **ประวัติเปิดบทเรียน** (IP, ⚠️ เปิดถี่ผิดปกติ)
  - ลบสมาชิก (ถาวร)

### 🏷 โค้ดส่วนลด
- **"+ สร้างโค้ด"**: โค้ด (A–Z 0–9 - _) · คำอธิบาย (ทีมงานเห็นเท่านั้น) · ลด **%** หรือ **บาท** · ใช้กับคลาสไหน (ไม่เลือก = ทุกคลาส) · ใช้ได้กี่ครั้ง · วันหมดอายุ · 1 คนใช้ได้ครั้งเดียว · เปิดใช้งาน
- ตาราง: ใช้ไปกี่ครั้ง / ลดไปรวมเท่าไร · กดป้ายสถานะเพื่อ **เปิด/ปิด** · แก้ไข · ลบ
- นับการใช้จากสลิปที่ยังไม่ถูกปฏิเสธ (ปฏิเสธแล้ว = คืนสิทธิ์ใช้โค้ด)
- กันสุ่มเดา: กรอกผิดเกิน 10 ครั้ง/10 นาที ระบบให้พัก

### ▶ คอร์ส & วิดีโอ
- สร้าง/แก้คอร์ส: ชื่อ, คำอธิบาย, ผู้สอน, หมวด, ราคา, รูปปก, อายุสมาชิกเริ่มต้น (วัน · ว่าง = ไม่หมด)
- **วิดีโอ**: เพิ่ม/แก้/ลบ · ลากเพื่อเรียงลำดับ
  - **วางลิงก์ YouTube → ระบบดึง ชื่อคลิป / คำอธิบาย / ความยาว มาให้เอง** (ช่องที่พิมพ์ไว้แล้วไม่ถูกทับ · แก้ต่อได้)
  - ภาพปกบทเรียนดึงจากภาพปกคลิป YouTube อัตโนมัติ · คลาสที่ยังไม่มีรูปปก ใช้ภาพคลิปแรกให้เอง
  - ฟอร์มแก้คอร์สมีปุ่ม **"🎬 ใช้ภาพจากคลิปแรก"** เป็นรูปปกคลาส
  - YouTube ต้องตั้งเป็น **Unlisted** (Private เล่นบนเว็บไม่ได้) · Google Drive ต้องแชร์ "ทุกคนที่มีลิงก์"

  - ใน Google Drive ตั้งแชร์เป็น "ทุกคนที่มีลิงก์ (ผู้มีสิทธิ์อ่าน)" แล้ววางลิงก์ + ตั้งชื่อ
  - ลิงก์จริงไม่อยู่ในหน้าเว็บ · สมาชิกกดแล้วระบบตรวจสิทธิ์เรียนก่อนพาไป · บันทึกใน Log สมาชิก ("เปิดเอกสารประกอบคลาส")

## 10. ปัญหาที่เจอบ่อย + วิธีแก้
| อาการ | ทำอย่างไร |
|---|---|
| สมาชิกบอก "บัญชีนี้กำลังใช้งานอยู่ที่อุปกรณ์อื่น" | ให้ออกจากระบบที่เครื่องเดิม หรือ Admin → สมาชิก → **ปลดล็อกอุปกรณ์** |
| สมาชิกเข้าไม่ได้ "ยังไม่ได้ยืนยันอีเมล" | Admin → สมาชิก → กรอง "รอยืนยันอีเมล" → **ยืนยัน** |
| ซื้อคลาสไม่ได้ ขึ้นให้กรอกข้อมูล | ให้สมาชิกกด "ไปกรอกข้อมูล" กรอกช่องสีส้มให้ครบ |
| โค้ดส่วนลดใช้ไม่ได้ | ดูข้อความที่ขึ้น (หมดอายุ / ครบจำนวน / ใช้ไม่ได้กับคลาสนี้ / ใช้ไปแล้ว) · เช็กที่ Admin → โค้ดส่วนลด |
| วางลิงก์ YouTube แล้วไม่ดึงข้อมูล | คลิปต้องเป็น Unlisted/Public · ถ้ายังไม่ได้ ใส่ `YOUTUBE_API_KEY` ใน Vercel แล้ว Redeploy |
| ปุ่มอนุมัติไม่ขึ้นใน Discord | Admin → Usage → "ทดสอบปุ่มอนุมัติใน Discord" จะบอกสาเหตุ (บอทไม่อยู่ในเซิร์ฟเวอร์ / ไม่มีสิทธิ์ห้อง / Channel ID ผิด) |
| วิดีโอ Drive ขึ้น "ลงชื่อเข้าใช้ Google" | Drive จำกัดเมื่อเปิดบ่อย → ย้ายคลิปไป YouTube Unlisted |
| สมาชิกเปิดบทเรียนไม่ได้ "เปิดถี่เกินไป" | ระบบพักขอลิงก์ ~1 ชม. (กันดูดคลิป) · ดูประวัติที่หน้าสมาชิก |
