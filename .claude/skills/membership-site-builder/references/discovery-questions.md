# คำถามก่อนเริ่มโปรเจกต์ (Discovery)

ถามเป็นชุดสั้นๆ ไม่ต้องถามทีเดียวทั้งหมด — เริ่มจากกลุ่ม A ก่อนสร้างอะไร กลุ่มอื่นถามตอนถึงขั้นนั้น
คำตอบทุกข้อจดลง `docs/OWNER_PREFERENCES.md` (ถ้ายังไม่มีให้สร้างจาก template ท้ายไฟล์นี้)

## A. ธุรกิจ & คอร์ส (ต้องรู้ก่อนเขียนหน้าเว็บ)
1. ชื่อแบรนด์ / ชื่อบริษัท / ชื่อที่ใช้บนเว็บ (เช่น THUS House of Traders)
2. มีคอร์สอะไรบ้าง — ชื่อ, ราคา, อายุสมาชิก (วัน), ผู้สอน, คำอธิบาย
   - มีคอร์สหลักคอร์สเดียวหรือหลายคอร์ส? มีคอร์สฟรี/ทดลองไหม?
3. ขายแบบซื้อครั้งเดียว หรือสมาชิกรายปี/รายเดือน? หมดอายุแล้วต่ออายุยังไง?
4. รับเงินช่องทางไหน — ธนาคาร, ชื่อบัญชี, เลขบัญชี (แสดงหน้าชำระเงิน)
5. เงื่อนไขพิเศษที่ต้องแสดง (เช่น "สงวนสิทธิ์ในการคืนเงินทุกกรณี")
6. สโลแกน / tagline ที่อยากใช้ (THUS: "Winners Average Winners")
7. สิ่งที่สมาชิกได้ (Highlights / Benefits / หัวข้อบทเรียน) — ขอข้อความจริงมา ไม่แต่งเอง

## B. แบรนด์ & ดีไซน์
1. ขอไฟล์ CI: โลโก้ (ไฟล์ใหญ่ที่สุดที่มี), สไลด์/โพสต์ที่ชอบ, สีหลัก
2. ฟอนต์ที่ชอบ (ภาษาไทย + อังกฤษ) — ถ้าไม่แน่ใจ ใช้ Inter + IBM Plex Sans Thai
3. โทนหน้าแรก: สว่าง / มืด / มีปุ่มสลับ? ค่าเริ่มต้นเป็นแบบไหน? (THUS: มืดเป็นค่าเริ่มต้น + ปุ่มสลับ)
4. มีวิดีโอแนะนำหน้าแรกไหม (ลิงก์ YouTube) — ให้เล่นอัตโนมัติหรือกดเอง?
5. มีรูปจริงไหม: รูปผู้สอน, รูปกิจกรรม (Meetup), รีวิว/Feedback (ต้องขออนุญาตเจ้าของข้อความแล้ว)
6. หน้าอ้างอิงที่ชอบ (เว็บคนอื่น) — ถามว่าชอบ "ตรงไหน"

## C. ระบบ & สิทธิ์
1. อีเมล Admin เจ้าของระบบ (ใส่ใน `NEXT_PUBLIC_ADMIN_EMAILS` = ได้ทุกสิทธิ์เสมอ)
2. ต้องมีทีมงานหลายระดับไหม (Admin / Head Admin / ผู้ช่วยสอน) — ใครทำอะไรได้
3. วิดีโออยู่ที่ไหน (Google Drive / YouTube unlisted / Bunny) — ต้องกันลิงก์หลุดแค่ไหน
4. มีเรียนสด (Zoom/Discord/YouTube Live) ไหม วันเวลาไหน
5. ต้องการส่งอีเมลประกาศจาก Admin ไหม (ต้องมี Brevo API key)

## D. บัญชีบริการ (ถามตอนถึงขั้น deploy)
1. GitHub repo ชื่ออะไร
2. มีบัญชี Supabase / Vercel แล้วหรือยัง (ใช้ MCP ตรวจได้เอง — ถามเฉพาะที่ตรวจไม่ได้)
3. โดเมนซื้อแล้วหรือยัง ซื้อที่ไหน (GoDaddy / อื่นๆ)
4. มีบัญชี Brevo ไหม (สำหรับอีเมลยืนยันและประกาศ)

## E. วิธีทำงานร่วมกัน
1. อยากเห็นภาพตัวอย่างก่อน deploy ทุกครั้งไหม หรือเฉพาะงานดีไซน์
2. คำไหนแปลว่า "ขึ้นเว็บได้" (THUS: "deploy ได้", "จัดไป", "ลุย", "อะลองดู")
