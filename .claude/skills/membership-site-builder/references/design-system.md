# Design system & หลักจัดหน้า

## จาก CI → โทนเว็บ
1. ขอไฟล์โลโก้/สไลด์ → ดึงสีด้วย PIL (sample pixel จากพื้นหลังและองค์ประกอบหลัก)
2. ตัดโลโก้พื้นโปร่งใส 2 สี (ขาวสำหรับพื้นเข้ม / สีแบรนด์สำหรับพื้นอ่อน) + mark เป็น favicon (`src/app/icon.png`) — `scripts/extract_brand.py`
3. ใส่สีใน `tailwind.config.ts`; สีที่ต้องสลับโหมดมืด/สว่างให้เป็น CSS variable (`rgb(var(--x) / <alpha-value>)`)

THUS palette: plum `#2d183c / #3a2449 / #473654 / #6a5c73`, paper `#e3e2dd`, glow lilac `#ba94c7` blue `#9195dc` orange `#ec9e56` pink `#e3a3a8`

## ตัวอักษรภาษาไทย (สิ่งที่เจ้าของสังเกตเสมอ)
- ฟอนต์: Inter + IBM Plex Sans Thai (โหลดน้ำหนักถึง 800) — **ไม่มีตัวเอียงจริง อย่าใช้ italic** (เบราว์เซอร์เอียงปลอมดูไม่สวย)
- **ห้ามให้วลีสำคัญถูกตัดกลาง** เช่น "ทักษะการ/เทรดจริง", "ปรับพื้น/ฐาน", "20:30 –/22:30 น." → ครอบด้วย `whitespace-nowrap`
- ช่องว่างระหว่าง span แบบ nowrap ต้องอยู่**นอก** span (ช่องว่างใน nowrap ไม่ใช่จุดตัดบรรทัด)
- เจ้าของพิมพ์จุดขึ้นบรรทัดมาเอง → จอ md ขึ้นไปตัดตรงตามนั้น (`md:block md:whitespace-nowrap`), มือถือให้ไหลตามจอแต่ยังกันวลี
- อย่าเติมช่องว่างที่ต้นฉบับไม่มี (เช่น "เทรดเดอร์ ตั้งแต่")
- ขนาดหัวข้อใช้ `clamp()` + ลดขนาดช่วงโน้ตบุ๊ก, `leading` แน่น (~0.86) สำหรับหัวข้อตัวใหญ่
- `[text-wrap:pretty]` สำหรับย่อหน้า, ปุ่มบนมือถือเต็มความกว้างเรียงลง

## Dark mode
- Tailwind `darkMode: "class"`, class `dark` บน `<html>` เป็นค่าเริ่มต้น (THUS ใช้ dark เป็น default), script ใน `<head>` ลบออกถ้าผู้ชมเคยเลือก light — กันกระพริบ
- แสงฟุ้งสีส้ม/ชมพูบนพื้นมืดดูเป็นสีน้ำตาลหม่น → สลับเป็นม่วง/ฟ้าในโหมดมืด
- gradient text ที่ override `dark:from-*` ต้องใส่ `dark:to-*` ซ้ำ (ไม่งั้นปลายสีโปร่งใส)
- โลโก้พื้นอ่อนต้องสลับเป็นโลโก้ขาวในโหมดมืด
