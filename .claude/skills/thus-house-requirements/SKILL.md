# THUS House — ความต้องการของเจ้าของ (Spec ที่ตกลงแล้ว)

ไฟล์นี้คือ "กติกาที่เจ้าของตกลงแล้ว" — ห้ามเปลี่ยนพฤติกรรมเหล่านี้เองโดยไม่ถามเจ้าของ
- ความชอบด้านดีไซน์ / วิธีสื่อสาร → `docs/OWNER_PREFERENCES.md`
- คู่มือการใช้งานทุกฟังก์ชัน (ภาษาคนทั่วไป) → `docs/USER_GUIDE.md` (เพิ่ม/เปลี่ยนฟีเจอร์ = อัปเดตไฟล์นี้ด้วย)
- วิธีทำงาน / deploy / ภาพตัวอย่าง / ข้อผิดพลาดที่เคยเจอ → skill `membership-site-builder`
- ความปลอดภัย + checklist ก่อน merge → `references/security.md`
- แผนที่โค้ดของแต่ละกติกา → `references/code-map.md`

## 0. วิธีทำงานกับเจ้าของ (สรุป)
- ตอบภาษาไทย สั้น ง่าย ไม่พูดซ้ำ · งานที่ตาเห็น → ส่งภาพตัวอย่าง (ข้อมูลสมมติ) รอ "จัดไป / ลุย / deploy ได้" ค่อย merge
- งานหลังบ้าน / แก้บั๊ก / แก้ข้อความ / ปุ่มเล็กใน Admin → ทำได้เลย
- Vercel **Pro** แล้ว (25 ก.ย. 2569) — deploy ได้ไม่ติดลิมิต · preview build ของ `claude/*` ปิดไว้ใน `vercel.json`
- ความลับ (token, key) ห้ามพิมพ์ในแชท — เจ้าของใส่เองใน Vercel · ห้ามถอดรหัส env

## 1. Role & สิทธิ์ (ลำดับชั้น — เจ้าของกำหนด)
| Role | สิทธิ์ |
|---|---|
| Head Admin | ทำได้ทุกอย่าง · แก้นิยาม Role (สร้าง/แก้/ลบ) · จัดการ Head Admin คนอื่น · ดูเว็บในมุมมอง Mentor/Member |
| Admin | ทุกเมนู **ยกเว้น** เปลี่ยน Role ตัวเอง · แตะบัญชี Head Admin · แก้นิยาม Role |
| Mentor | สูงกว่า Member: เลือกสมาชิกมาดูแล + จดโน้ต · ไม่เห็นเลขบัตร/ที่อยู่ |
| Member | เรียนคอร์สที่ซื้อ |
- 1 คนหลาย Role: Role หลัก (`users.role`) + Role เพิ่มเติม (`user_roles`) → สิทธิ์รวมกัน
- ให้/ถอด Role ได้เฉพาะที่ **ต่ำกว่า** ตัวเอง (Head ให้ได้ทุกอย่าง) · อีเมลใน `NEXT_PUBLIC_ADMIN_EMAILS` = Head เสมอ
- มุมมองจำลอง (cookie `thus_view_as`, 12 ชม.): เปลี่ยนแค่สิทธิ์ที่ "เห็น" (`getPermissions`) — การตัดสินลำดับชั้นใช้สิทธิ์จริง (`getRealPermissions` / `userRank`)

## 2. บัญชี & ล็อกอิน
- สมัคร: ชื่อ–นามสกุล, ชื่อเล่น, เบอร์, **วันเกิด (วัน/เดือน/ปี พ.ศ.)**, อีเมล, รหัสผ่าน · ส่งอีเมลยืนยันไม่ได้ → สมัครได้แต่รอ Admin "ยืนยันแทน"
- **สมาชิกล็อกอินได้ทีละ 1 เครื่อง** · ต้องออกจากระบบเครื่องเดิมก่อน · เครื่องเดิมเงียบ > 24 ชม. ปล่อยเอง · Admin "ปลดล็อกอุปกรณ์" ได้ · ทีมงาน (role ≠ member) ไม่ล็อก
- สถานะ: active / inactive (ดูวิดีโอไม่ได้) / suspended (ล็อกอินไม่ได้)

## 3. โปรไฟล์
- สมาชิกแก้เองได้: รหัสสมาชิก (A–Z 0–9 - _, ห้ามซ้ำ), ชื่อ, ชื่อเล่น, เบอร์, วันเกิด, เลขบัตร, ที่อยู่, ตลาดที่เคยเทรด, ประสบการณ์, เป้าหมาย, รูปโปรไฟล์ (ย่อเหลือ 256px WebP)
- **เลขบัตรประชาชน**: ตรวจ check digit · เก็บเข้ารหัส (pgcrypto + กุญแจใน Supabase Vault `id_card_key`) · แสดง `•••••••••1234` · เปิดเต็มได้เฉพาะเจ้าของบัญชี + Admin (สิทธิ์ members) · ทุกการเปิดโดย Admin ลง Audit Log + Log สมาชิก
- **ต้องกรอกครบก่อนซื้อคลาส**: ชื่อ, ชื่อเล่น, เบอร์, วันเกิด, เลขบัตร, ที่อยู่, ประสบการณ์, ตลาดที่เคยเทรด (ยกเว้น "ยังไม่เคยเทรด"), เป้าหมาย · รหัสสมาชิกไม่บังคับ · หน้าชำระเงินพาไปกรอก แล้วมีปุ่มกลับมาจ่าย · API ตรวจซ้ำ

## 4. ซื้อคลาส & โค้ดส่วนลด
- โอน + แนบสลิป → Admin อนุมัติ (เว็บ หรือปุ่มใน Discord) → เปิดสิทธิ์ตามอายุคลาส · ซื้อต่ออายุได้ · สงวนสิทธิ์คืนเงิน
- โค้ดส่วนลด: % หรือบาท · เลือกคลาส · จำกัดครั้ง · วันหมดอายุ · 1 คน/ครั้ง · เปิด/ปิด
  - สมาชิกเห็น ราคาเต็ม → ส่วนลด → ราคาสุดท้าย + **รหัสยืนยันโค้ด `D-XXXXXX`** (hash ของ โค้ด+คลาส+ผู้ใช้ — ทีมงานเห็นรหัสเดียวกันตอนตรวจสลิป) *(เป็นการตีความของ Claude — เจ้าของยังไม่ได้ขอเปลี่ยน)*
  - คำนวณฝั่ง server เสมอ · นับการใช้จากสลิปที่ยังไม่ถูกปฏิเสธ · ยอด 0 ไม่ต้องแนบสลิป · กรอกผิด > 10 ครั้ง/10 นาที = พัก

## 5. บทเรียน & ชุมชน
- วิดีโอ YouTube Unlisted (ปุ่มของเว็บเอง) / Google Drive · ส่งลิงก์ทีละบท · เปิด > 30 บท/ชม. = พัก + แจ้งทีมงาน
- ภาพปกบทเรียน = ภาพปกคลิป YouTube (`i.ytimg.com/vi/<id>/hqdefault.jpg`) · คลาสไม่มีปก → ใช้คลิปแรก · ปุ่ม "ใช้ภาพจากคลิปแรก"
- เพิ่มวิดีโอ: วางลิงก์ YouTube → ดึงชื่อ/คำอธิบาย/ความยาว (ไม่ทับช่องที่พิมพ์แล้ว) · ถ้าดึงไม่ได้ ให้ใส่ `YOUTUBE_API_KEY`
- คอมเมนต์: ชื่อ = **รหัสสมาชิก + ชื่อเล่น** + รูปโปรไฟล์ · ตอบได้ 1 ชั้น · **สมาชิกลบได้เฉพาะของตัวเอง** · ทีมงาน (community) ลบได้ทุกอัน
- หัวใจบทเรียน: กดดูรายชื่อคนที่กดได้
- การ์ดคลาส: ทรงเกือบจัตุรัส (ปก 16:9, Dashboard สูงสุด 4 ใบ/แถว)

## 6. Mentor
- เลือกจาก **รายชื่อสมาชิกที่ยังไม่มี Mentor** (คนที่ Mentor อื่นเลือกแล้วไม่ขึ้น) · 1 สมาชิก = 1 Mentor
- เห็น: ข้อมูลติดต่อ, วันเกิด, ประสบการณ์, เป้าหมาย, คอร์ส, กิจกรรม 30 รายการ · จดโน้ต (สมาชิกไม่เห็น, ลบได้เฉพาะของตัวเอง)

## 7. Admin
- แก้หลายคนพร้อมกัน (รหัส / ชื่อเล่น / สถานะ, ทีละ 200)
- Log สมาชิก (180 วัน) + Audit Log ทีมงาน
- **ออนไลน์ & สถิติ**: ping ทุก 60 วิเฉพาะตอนเปิดแท็บ · ห่าง > 3 นาที = ครั้งใหม่ · ออนไลน์ = ping ใน 2 นาที · อันดับเวลารวม/จำนวนครั้ง · วันนี้/7/30 วัน · เก็บ 180 วัน
- Usage: Supabase / Brevo / Vercel Pro + วันต่ออายุ

## 8. แจ้งเตือน & อัตโนมัติ
- Discord: สมัคร, สลิป (+โค้ด), อนุมัติ/ปฏิเสธ, คอมเมนต์, ข้อความ, เปิดบทเรียนถี่, Usage 80%, สิทธิ์เหลือ 30/7/1 วัน, **Vercel ต่ออายุพรุ่งนี้ (ทุกวันที่ 24, ต่ออายุวันที่ 25)**
- Cron 09:00: usage, สิทธิ์ใกล้หมด, ต่ออายุ Vercel, **รายงานประจำวัน (สถิติเมื่อวาน → ห้อง Backup)**, backup เข้า Discord, ลบ Log/ออนไลน์ > 180 วัน

## 9. สิ่งที่ยังค้าง / ข้อเสนอ
- อัปเกรด Next.js 14 → 15/16 (npm audit แจ้งช่องโหว่ที่แก้เฉพาะเวอร์ชันใหม่ · ส่วนใหญ่ไม่กระทบเว็บบน Vercel) — ต้องทำเป็นงานแยก + ทดสอบทั้งเว็บ
- เปิด "Leaked password protection" ใน Supabase Auth (ต้องใช้ Supabase Pro)
- ย้ายคลิป Drive → YouTube Unlisted · Bunny Stream (รอตัดสินใจ)
